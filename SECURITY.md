# Security policy

SubmissionLedger v0.1 is an early local-first release, not a production-ready intake service. Read [Design and limitations](docs/DESIGN.md) before storing sensitive data.

## Reporting a vulnerability

Please do **not** include exploit details or private data in public GitHub issues. Use GitHub's private vulnerability reporting feature for this repository if enabled. If it is unavailable, open a minimal issue asking for a private reporting channel, without publishing technical details.

## Supported versions

Only the most recent release line receives fixes. There is no long-term support promise before v1.0.
